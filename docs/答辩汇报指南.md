# AirInsight 空气质量监测平台 — 答辩汇报指南

## 一、项目一句话

> AirInsight 是一个企业级 SaaS 空气质量监测平台，从设备数据采集到 AI 报告生成全链路闭环。已部署在阿里云，HTTPS 公网可访问。

## 二、技术架构（必讲，体现复杂度）

```
                        ┌──────────────────────────────────────┐
模拟器/真实设备 ──HTTPS──>  Flask API (Nginx 反向代理)
    (31省/247设备)         │   ├── Redis Stream（消息队列缓冲）    │
                           │   ├── Consumer（批量消费 → MongoDB） │
                           │   ├── APScheduler（定时日统计）       │
                           │   └── Alert Checker（告警引擎）       │
                           └──────────────────────────────────────┘
                                         │
              ┌──────────────────────────┼──────────────────────┐
              ▼                          ▼                      ▼
         MySQL (业务数据)           MongoDB (时序数据)         Redis (缓存+限流)
      客户/设备/工单/报告           18,000+条空气质量记录        Token/验证码/速率
```

**技术栈**：Python Flask + Vue3 + Element Plus + ECharts + MySQL + MongoDB + Redis + Nginx + Docker

## 五、回答老师可能问的问题

**Q: 数据是真的吗？**
A: 有模拟器程序，覆盖 31 省 247 台设备，每 3 秒发一条带地理位置和用户的真实格式数据。也支持真实设备接入。

**Q: 并发怎么保证？**
A: 三层——Redis Stream 缓冲削峰 + Consumer 批量写入 MongoDB + MongoDB/Redis 连接池（100/50最大连接）。

**Q: 安全怎么做的？**
A: 验证码防机器人 + 登录限流防暴力破解 + HSTS/X-Frame/XSS 安全头 + Redis Token 24h 过期 + 角色权限分级。

**Q: 商业价值在哪？**
A: 不是做"空气监测工具"，是做"空气质量数据分析服务"。卖报告给地产商/酒店/学校（含图表+表格+AI分析+PDF），从"卖设备"升级到"卖数据服务"。

**Q: 有什么创新？**
A: DeepSeek AI 自动生成分析报告（带环比对比+行业定制+逐设备分析），CR M客户驱动的报告生成，企业模式模拟器。
