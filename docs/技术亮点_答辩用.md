## 1. 三库协同架构 ⭐⭐⭐⭐⭐ (必讲)

**MySQL → MongoDB → Redis 三种数据库各司其职：**

| 库 | 用途 | 数据量 |
|----|------|--------|
| MySQL | 业务数据 (客户/设备/工单/报告/审计) | 10 张表，534 条审计日志 |
| MongoDB | 时序数据 (空气质量) | **62 万条**，26 省 27 市 247 设备 |
| Redis | 缓存 + 消息队列 + Token + 限流 | 在线会话、Stream 队列、验证码 |

**讲法**："不是用一个数据库搞定所有事，而是按数据特性选型。业务关系型用 MySQL，时序大数据用 MongoDB，高频读写用 Redis。三个数据库通过 device_id 串联形成完整链路。"

## 2. 消息队列削峰 + 批量写入 ⭐⭐⭐⭐

```
模拟器(247台×3秒/条) → HTTPS POST → Redis Stream → Consumer(批量)
                                                          ↓
                                                    MongoDB 批量写入
```

**讲法**："247 台设备每 3 秒一条数据，如果直写 MongoDB 会被打死。Redis Stream 作为缓冲队列，Consumer 批量消费后一次写入 MongoDB，既保护了数据库，又提高了吞吐量。这是生产级的数据接入方案。"

> 展示：`redis-cli XLEN data_stream` 可以看到队列积压量

## 3. AI 驱动报告生成 ⭐⭐⭐⭐⭐ (最大亮点)

```
CRM客户(万科地产集团) → 查名下设备 → MongoDB 5项聚合
    ├── 总体统计 (均值/最高/最低/达标率)
    ├── 日分解 (每天趋势)
    ├── 等级分布 (优/良/轻度/重度)
    ├── 逐设备排名 (每台设备的AQI/PM2.5/达标率)
    └── 超标统计 (PM2.5/NO2/SO2/O3 超标率)
        ↓
    DeepSeek API → 行业定制分析 (地产→商业地产室内环境)
        ↓
    前端: ECharts图表 + 数据表格 + PDF导出
```

**讲法**："不是简单的数据展示——从 CRM 选客户、到聚合客户名下所有设备的数据、到 AI 结合客户行业生成定制分析、再到图表+表格+多页 PDF 一键导出。这是一个可商业化交付的完整产品。"
> 展示：打开已生成的报告 → 点预览 → 看图表+四张表 → 导出 PDF

## 4. 安全纵深防御 ⭐⭐⭐⭐

| 层级 | 措施 | 演示方式 |
|------|------|---------|
| 传输层 | HTTPS + HSTS | 浏览器地址栏🔒 |
| 应用层 | 数学验证码 | 登录页展示 `3+7=?` |
| 认证层 | Redis Token (24h过期) | 退出需重新登录 |
| 防护层 | X-Frame-Options: DENY / XSS / nosniff | F12 → Network → Response Headers |
| 限流层 | 登录 5次/5分钟/IP | 输错 5 次密码演示 |
| 密码层 | 8位+大小写+数字 | 新增用户时强制校验 |

**讲法**："6 层纵深防御，从传输到应用到数据库，每个环节都有安全措施。不是只加个 HTTPS 就算安全了。"

## 5. 连接池与缓存 ⭐⭐⭐

```
MongoDB: maxPoolSize=100, minPoolSize=5 (避免每次新连接)
Redis:   max_connections=50 (连接复用)
地图:    Redis 缓存 2 小时 (首次 20s，缓存后 0s)
```

**讲法**："单机 1.6GB 内存支撑 62 万条数据的查询分析，靠的就是连接池复用和 Redis 缓存。大查询只跑一次，后续请求直接走缓存。"

## 6. 区域三级下钻 ⭐⭐⭐

```
全国 → 选省份(重庆) → 选城市(重庆) → 选区县(渝中区) → 看到该区每台设备的具体AQI排名
```

**讲法**："不是静态地图，是真正能下钻到每台设备的实时数据可视化。"
