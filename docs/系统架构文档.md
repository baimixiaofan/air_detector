# AirInsight 智能空气监测平台 — 系统架构

---

## 一、技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue3 + Element Plus + ECharts + html2canvas + jspdf |
| 后端 | Python Flask (Blueprint 蓝图架构) |
| 数据库 | MySQL (业务) + MongoDB (时序) + Redis (缓存/队列/认证) |
| 代理 | Nginx (HTTPS 终止 + 反向代理) |
| 容器 | Docker (模拟器部署) |
| AI | DeepSeek API (报告生成 + 诊断分析) |
| 部署 | 阿里云 ECS Ubuntu 22.04 + Let's Encrypt 证书 |

## 四、安全架构

| 层级 | 措施 |
|------|------|
| 传输层 | HTTPS (Let's Encrypt) + HSTS |
| 应用层 | 数学验证码 + Redis Token (24h) + 角色权限分级 |
| 防护层 | X-Frame-Options: DENY, XSS-Protection, Content-Type-Options |
| 限流 | 登录 5次/5分/IP (Redis 计数) |
| 密码 | 8位+大小写+数字强制校验 |
| 安全头 | 5项 OWASP 推荐头部全部启用 |

## 五、并发架构

| 组件 | 措施 |
|------|------|
| MongoDB | 连接池 maxPoolSize=100, minPoolSize=5 |
| Redis | 连接池 max_connections=50 |
| 数据接入 | Redis Stream 缓冲 → Consumer 批量写入 |
| 重查询 | Redis 缓存 (device-distribution: 2小时) |
| Flask | 系统 systemd 自动重启 + 健康检查 |
