# AirInsight 前端架构

```
App.vue
├── LoginView                   登录 (验证码)
└── AppLayout                  主布局
    ├── SidebarMenu            侧边栏 (角色过滤: admin/ops/viewer)
    └── 页面
        │
        ├── DashboardView      运营看板 (设备/客户/工单/数据量 + 系统状态)
        ├── ChinaMapView       全国分布 (ECharts地图 → 省市下钻)
        ├── CustomerList       客户管理 (企业/个人 CRUD)
        ├── DeviceList         设备管理 (出厂编码 → 激活 → 在线/离线)
        ├── WorkOrderList      售后工单 (故障/维修/巡检/投诉)
        ├── RankingsView       区域排行 (省→市→区→设备 三级下钻)
        ├── PoorAirUsers       数据分析 (AQI超标用户 + CSV导出)
        ├── ReportsView        数据报告 ★
        │   ├── ReportCharts   ECharts图表 (趋势/对比/环形)
        │   └── ReportTables   数据表格 (逐设备/日均/超标/环比)
        ├── HistoryQuery       历史数据 (设备ID→时间范围→趋势图)
        ├── AlertRules         告警规则
        ├── AlertRecords       告警记录
        ├── CompanyInfo        企业信息
        ├── AdminUsers         管理员
        └── OperationLogs      操作日志
```

```
数据流:  Vue组件 → Axios (BearerToken) → Flask /api/admin/* → MySQL/MongoDB/Redis
```
