# 数据库文档

---

## 一、MongoDB — 原始时序数据

| 项目 | 值 |
|------|----|
| 主机 | `localhost:27017` |
| 数据库 | `air_quality` |
| 集合 | `records` |
| 用途 | 存储模拟器上报的原始空气质量数据（全量保存） |

### 文档结构

```json
{
  "timestamp":   "2026-05-15 14:30:00",   // 模拟器生成时间
  "server_time": "2026-05-15T14:30:01",   // 服务器接收时间（ISO8601）
  "device_id": "CQ_001",                  // 设备编码
  "client_ip": "172.17.0.2",              // 模拟器容器 IP
  "data": {
    "AQI":    68.5,    // 空气质量指数
    "PM₂.₅":  35.2,    // 细颗粒物 μg/m³
    "NO₂":    42.1,    // 二氧化氮 μg/m³
    "SO₂":    15.8,    // 二氧化硫 μg/m³
    "O₃":     55.3     // 臭氧 μg/m³
  }
}
```

### 关键索引

- 按 `timestamp` 排序查询历史数据
- 按 `device_id` + `client_ip` 联合查询特定设备

### 消费链路

```
模拟器 → HTTPS /api/air-quality → Redis Stream(data_stream)
                                          ↓
                              consumer.py → MongoDB records
```

## 二、MySQL — 业务数据

| 项目 | 值 |
|------|----|
| 主机 | `localhost:3306` |
| 数据库 | `air_quality` |
| 用户 | `air_user` |
| 用途 | 用户、设备绑定、日统计等结构化业务数据 |

### 表 1：`users` — 微信用户

```sql
CREATE TABLE users (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  open_id     VARCHAR(64) NOT NULL UNIQUE,    -- 微信 open_id
  nickname    VARCHAR(64),                    -- 微信昵称
  avatar_url  VARCHAR(256),                   -- 头像 URL
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 表 2：`user_devices` — 用户设备绑定

```sql
CREATE TABLE user_devices (
  id             INT AUTO_INCREMENT PRIMARY KEY,
  open_id        VARCHAR(64) NOT NULL,        -- 用户 open_id
  device_id      VARCHAR(64) NOT NULL,        -- 设备编码
  room_location  VARCHAR(32) DEFAULT 'living_room',  -- 设备所在房间
  bind_time      DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_device (open_id, device_id)
);
```

`room_location` 取值：`living_room`（客厅）、`bedroom`（卧室）、`kitchen`（厨房）、`study`（书房）、`balcony`（阳台）、`dining_room`（餐厅）、`bathroom`（卫生间）、`hall`（大厅）

### 表 3：`user_favorites` — 用户收藏设备

```sql
CREATE TABLE user_favorites (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  open_id     VARCHAR(64) NOT NULL,
  device_id   VARCHAR(64) NOT NULL,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_fav (open_id, device_id)
);
```

### 表 4：`user_alerts` — 报警阈值设置

```sql
CREATE TABLE user_alerts (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  open_id     VARCHAR(64) NOT NULL,
  device_id   VARCHAR(64) NOT NULL,
  aqi_max     DECIMAL(10,1),          -- AQI 报警上限
  pm2_5_max   DECIMAL(10,1),          -- PM2.5 报警上限
  is_enabled  TINYINT DEFAULT 1,      -- 是否启用
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_alert (open_id, device_id)
);
```

### 表 5：`devices` — 设备注册表

```sql
CREATE TABLE devices (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  device_id     VARCHAR(64) NOT NULL UNIQUE,   -- 设备编码
  location_name VARCHAR(128),                  -- 位置名称
  longitude     DECIMAL(10,6),                 -- 经度
  latitude      DECIMAL(10,6),                 -- 纬度
  api_key       VARCHAR(64),                   -- API 密钥
  status        TINYINT DEFAULT 0,             -- 状态（0=离线 1=在线）
  create_time   DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 表 6：`daily_summary` — 日统计汇总

```sql
CREATE TABLE daily_summary (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  device_id   VARCHAR(64) NOT NULL,       -- 设备编码
  stat_date   DATE NOT NULL,              -- 统计日期
  avg_aqi     DECIMAL(10,1),             -- 日均 AQI
  max_aqi     DECIMAL(10,1),             -- 日最高 AQI
  avg_pm2_5   DECIMAL(10,1),             -- 日均 PM2.5
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_date_device (stat_date, device_id)
);
```

由 `daily_stats_job.py` 每天 01:05 自动聚合写入，数据来源为 MongoDB records。

### 表 7：`air_quality_records` — MySQL 侧历史记录（未使用）

```sql
CREATE TABLE air_quality_records (
  id             INT AUTO_INCREMENT PRIMARY KEY,
  device_id      VARCHAR(64),
  aqi            DECIMAL(10,1),
  pm2_5          DECIMAL(10,1),
  pm10           DECIMAL(10,1),
  no2            DECIMAL(10,1),
  so2            DECIMAL(10,1),
  o3             DECIMAL(10,1),
  temperature    DECIMAL(10,1),
  humidity       DECIMAL(10,1),
  sample_time    DATETIME,
  create_time    DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

> **注意：** 该表未被自动化流水线填充，无实时数据写入。历史数据以 MongoDB 为准。

## 三、Redis — 消息队列

| 项目 | 值 |
|------|----|
| 主机 | `localhost:6379` |
| 用途 | 消息缓冲队列 |

### Stream

| Key | 用途 |
|-----|------|
| `data_stream` | 模拟器上报数据缓冲队列 |
| `dead_letter_stream` | 消费失败的死信队列 |

### 消费组

| 名称 | 消费者 |
|------|--------|
| `air_quality_group` | `consumer_1` |

### Hash

| Key | 用途 |
|-----|------|
| `simulator_stats` | 模拟器心跳状态（由 `air_detector.py` 上报） |
